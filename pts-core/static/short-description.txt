Ionity Bench is the Ionity Global benchmarking platform for edge, IoT, AI and server hardware, built on the Phoronix Test Suite engine. It ships Ionity-authored, fully offline test profiles (IO-Core, IO-Mem, IO-Thermal-Sustain, IO-Latency-RT, IO-AI-MatMul, IO-Telemetry-SQLite, IO-JSON-MQTT, IO-Crypto-Edge, IO-Storage-Edge, IO-Net-Loopback) and curated suites for edge nodes, IoT gateways, AI at the edge, storage, time-series databases, RMS servers and design workstations.

The underlying Phoronix Test Suite is the most comprehensive testing and benchmarking platform available for Linux, BSD, macOS, Solaris and Windows, carrying out qualitative and quantitative benchmarks in a clean, reproducible and easy-to-use manner. It consists of a lightweight processing core (pts-core) with each benchmark described by an XML profile and resource scripts, and integrates with OpenBenchmarking.org for additional test profiles, suites and result sharing.
